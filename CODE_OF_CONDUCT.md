# Code of Conduct

This project expects technical discussion to remain respectful, specific, and
focused on the work.

Contributors should:

- critique code, APIs, evidence, and design decisions rather than people;
- provide enough technical context for claims and bug reports to be evaluated;
- avoid harassment, discrimination, personal attacks, threats, or deliberate
  disruption;
- respect privacy and never publish another person's sensitive information;
- follow the repository's security reporting process for vulnerabilities.

Maintainers may edit, hide, lock, or remove contributions that materially
violate these expectations and may restrict participation when necessary to
protect the project and its contributors.

Good-faith disagreement is welcome. Clear technical criticism is welcome.
Abusive behaviour is not.
