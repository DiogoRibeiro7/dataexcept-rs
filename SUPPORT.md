# Support

Use the repository issue forms so questions and reports arrive with enough
context to investigate efficiently.

- Use **Bug report** for reproducible incorrect behaviour.
- Use **Feature request** for proposed functionality or API changes.
- Use **Question** for usage, integration, or documented behaviour.
- For security concerns, follow [SECURITY.md](SECURITY.md) and do not disclose
  vulnerability details publicly.

For protocol or interoperability questions, include the envelope schema version,
relevant JSON payload shape, and producer language when possible.

For build problems, include the crate version, Rust version, enabled features,
and the failing command or CI output.
